## 3. 跨族适配而非全族统一物理规则

化学家族、结构家族、电子 motif、研究 lane、科学 profile、评分模板是不同轴。本轮将示例中原先混作 family 的 Conventional / Layered / Kagome 拆开；界面对象还必须有各层组成，不用一个 reduced formula 充当完整结构身份。真实数据接入时 family 应允许多个化学类别；当前单选过滤器只是示例导航。

Profiles 可以叠加：

- EPC + multiband：保留平均 EPC 与带分辨耦合的区别。
- Correlated + layered：氧位点、掺杂、轨道、U/W、交换/竞争序与几何。
- Flatband + interface：扭角、填充、隔离能隙、屏蔽、栅控、量子几何与相干。
- F-electron + correlated：Kondo/正常态相干温标、正常态 γ、Z、f 价态。
- Organic / molecular：组成与分子堆积通过结构产物承载，活性分子轨道可走 correlated/layered 接口；不强行套金属原子轨道定义。

Profile 只决定推荐关注的描述符，不证明机制，不自动产生 N/A，也不重新计算分数。此目录支持扩展到不同家族，**不宣称已为所有材料建立有效且校准的统一预测器**。

## 4. 每个单元格的最小契约

已知结果采用判别类型 `number / text / artifact`：

- 数值：规范单位；exact、单侧界或 interval；误差及其定义；可保存原值/原单位/转换版本。禁止把区间自动取中点。
- 归一化：DOS、γ、莫尔填充、量子度规、超流权重必须附定义；其他量按字段上下文补。
- 来源：state/event/result ID、Observed/Computed/Inferred/AI-Proposed、原文定位、方法、审核、context；synthetic 是独立隔离标记。
- 谱、矩阵、张量、结构与计算 manifest 用 artifact 引用，不在表中伪造一个统一标量。

状态分别显示：**未知、未报告、待提取、未计算、不可取得、计算失败、有争议、不适用**。不适用必须给出本模型/状态下的理由；“任务不要求/预算不做”不属于不适用。真正的 0、负的能量差和负填充照常显示。

显示守卫会拒绝错状态、错类型、单位不匹配、非有限数、无效区间/误差、必需归一化缺失的“已知”值，显示原因。它不替代未来 importer 的科学校验、实体匹配或依赖闭包。

实验 NER 抽取仍是 Observed + LLM-extracted，不变成 AI-Proposed；本次 mock 的 AI-Proposed 明确伴随 synthetic，不代表观测或预测成果。未知来源不能默认审核通过。

## 5. 关键科学与 ML 防误用约束

1. λₑₚ 无量纲，λL 是长度；二者不同键。ωlog 用 K 时能量为 kBωlog，不再乘 ℏ。
2. n₂D 与 n₃D、方块电阻与体电阻率分键；不随意假设厚度转换。DOS 不统一冒充每 f.u. 自旋求和。
3. 形成 E/H 与相间 G 分开；凸包需同压力和参考相。虚频负号只是显示约定，核/非谐近似和 q 域决定判断范围。
4. U/W 与 hopping 比值需同子空间/定义；分母与误差同量级时未定义/给界限，可靠的大比值不人为截断。
5. 空间群、拓扑、磁性、平带、DOS、λ 均不自动对应全族正/负分。原始量只在被审核的联合 profile 规则中解释。
6. Tc 与目标相关比值、实测超导态 ξ/λL/刚度等默认后验；独立前瞻计算的例外需要具体任务审核，不能只改 UI 标签。
7. 配对机制主张、solver、结构证据状态默认审计字段，避免包含答案/研究选择偏差；条件化特征也不自动准入 ML。
8. 无转变必须带测温窗口/检测限，不能当 Tc=0。预测 Tc 单独显示；RPS 不是超导标签或 Tc 物理输入。
9. 缺字段不增加 G，新增相似字段也不重复加物理积分；分组/列筛选不改变当前固定评分。

## 6. 与当前数据库/API 的映射边界

| 展示字段 | 当前权威承载 / 后续处理 |
| --- | --- |
| pressure/state/sample/structure | material_states / research_samples / structure_records，导入前核验完整归属 |
| formation_energy_per_atom、energy_above_hull、band_gap、electron_phonon_lambda、omega_log、phonon_min_frequency | 复用 0045 已有同名属性定义和规范单位；当前页面没有直接查询这些影子表 |
| dos_ef | 通用展示语义；旧 dos_at_fermi 仅允许 states/eV/formula_unit。必须确认 f.u. 与 spin 等约定才能适配，不直接别名复制 |
| phase_stiffness / superfluid_weight | 不直接映射旧 superfluid_stiffness(K)；先审查定义、维度、前因子、张量与归一化，不能仅乘 kB 假装语义一致 |
| 实验 Tc 各判据 | material_claims；通过具体 event/criterion 关联。严禁另建重复真值属性或从 tc_max 拼值 |
| 模型 Tc | 原有模型结果/来源类别契约；不得覆盖实验 claim |
| 其余 extension | 新的经过审核的 property/structure/state/artifact 注册定义与 loader，不能把展示 key 自动写入当前严格数据库 |
| RPS/P/G/A | 原 RPS-v1.2 发布契约不变；前端字段增加不改变 policy/release |

完整的数值冲突分支、原文多来源、磁构型/温压区间、revision/hash、跨来源匹配与真实可复现产物，需要正式 loader 和版本化 release 承载。本轮文案与占位结构不是它们已经建成的证明。

## 7. 页面与测试

默认仍为“一材料一行”，材料名/总分固定在两侧，中间六个概览字段。选择科学分组后默认前六列，“显示列”可勾选或显示本组全部；仍然是一行。字典提供全部 126 个字段；点击表头看定义，点击值看该状态的来源/单位/缺失原因。详情在表外，支持焦点移动及关闭返回触发器。

16 个演示材料涵盖硼化物、氢化物、铁基、铜氧、镍基、硫属化合物、Kagome 结构示例、重费米子、莫尔双层、有机和界面对象。**所有数值、条件、profiles、行动、评分均为排版合成数据，即使材料名真实。** 未填字段保留未知，不按家族补造。

验证覆盖所有字段组可显示、列切换不改变行/积分、搜索与 profile 过滤、同分排名、空值/真零、N/A 原因、后验标识、单位/区间/归一化/状态拒绝、焦点行为与真/假数据隔离。生产构建与 HTTP smoke 在本地执行；未做浏览器截图、辅助技术实机或生产数据验收。

最终结果：源码测试 28、组件/契约测试 33，合计 **61 passed**；带 `/sclib` basePath 的生产构建通过；开发预览 HTTP 200。
