# Materials 页信息补全与显示优化综合方案

日期：2026-10-01；2026-10-02 追加实际第三方数据核查、第二轮来源恢复与显示改进。面向 SCLib 材料目录、材料详情页及其证据检索流程。

本方案整合用户提供的两张页面截图、跨页抽样、生产数据的只读试点和当前升级工作。公开界面继续使用英文。本文件说明哪些工作已在代码或试点中完成、哪些仍需核查；上线状态以正式发布后的公开页面验证为准。

## 执行概要

先让研究者看清已有结果，再逐批补足证据和条件。每个缺口先按“可从来源恢复、可查询外部参考、需要新计算、需要实验或原始记录”分流；没有合格证据的字段保留明确的缺失原因。

| 工作 | 具体改动 | 完成判据 |
| --- | --- | --- |
| 首屏和筛选 | 标题加一句介绍；方法说明默认收起；基础与高级筛选分开；统一标签、输入高度、网格和操作按钮 | 桌面与手机控件对齐；首屏能看到有效结果；URL、返回和清除行为一致 |
| 默认列表 | 保留七个核心列；无异常的操作提示移入方法说明；科学分类和结构改为可选列 | Tc、压力、origin 和来源年份属于同一结果；真实异常有明确入口；长公式和窄屏不裁切 |
| 来源恢复 | 从当前合格来源取正文、表格、图注和补充材料；优先定位已有 Tc 及其压力、方法、判据 | 每条表达有原值、单位、条件、版本和定位；明确核查范围；未查完不写“论文未报告” |
| 外部参考 | MDR 补对应文献的超导参考，COD 补结构，MP / NOMAD 补已有计算与任务方法 | 组成命中与样品 / 相匹配分开；多相、计算类型和条件可见；参考不覆盖已选实验结果 |
| 持续补全 | 接收新来源；追加表达修订；记录关联提案、核查尝试和未解决原因 | 可重复运行并保留旧版；不同模型、判据和窗口并列；待核查与正式属性分别统计 |
| 计算和实验 | 对可信来源仍无法回答、且有明确科学用途的缺口形成任务 | 输入、方法、条件、资源与验收明确；计算标为 Computed；实验事实由测量支持 |

首批200项材料任务队列已经提出，对应200个不同材料；每项包含多个字段缺口，并非200个新增事实或独立实验。执行前须重新核对上线版本中的材料、结果和来源资格。建议以每批10–20个材料推进，先反馈身份、单位和条件错误，再扩大到500–1,000个优先材料。扩大规模前的准确率门槛是建议目标，需要人工基准集验证；本次跨页样本和AI辅助核查不代表全库准确率。

第一阶段交付界面和只读证据入口，第二阶段交付来源核查与有权限的追加流程，第三阶段扩展结构 / 计算参考及少量科学问题试点。代码合并、本地验收、正式部署和公开验收分别记录，不能互相替代。

## 1. 目标与优先顺序

材料页首先应回答四个问题：这是什么材料；论文报告了什么性质；在什么条件下得到；证据在哪里。信息完整不等于每个格子都有数值，而是已有数值可追溯，适用条件足够明确，未知原因可解释，冲突结果可比较。

优先级按信息价值和可验证性排序：

1. **P0：恢复已有数据的可读性与证据链。** 修复顶部和筛选布局，减少重复政策文字，使 Tc、压力、来源、实验或计算属性来自同一个结果记录；优先补现有 Tc 的来源定位、压力、方法和判据。
2. **P1：重新检索对应论文及补充材料。** 将可明确归属材料和样品的正文、表格、图注转为待核查候选；复核后再进入正式属性记录。
3. **P2：接入第三方参考数据。** 对精确组成查询 MP，对结构资料评估 COD，对已有计算评估 NOMAD，并接入有版本与许可的 NIMS MDR SuperCon 性质参考；以独立参考条目展示，逐项判断相、条件和样品是否匹配。
4. **P3：为剩余有科学价值的缺口制定计算或实验任务。** 不因页面有空格就启动计算；先判断缺少的是文献提取、数据库检索、理论结果，还是只能通过实验判断的事实。

设计判断：这是研究人员使用的科学目录，保留 SCLib 绿色品牌和材料表格，采用清楚、紧凑、可比较的布局。依照 `design-taste-frontend` 的适用原则进行审计后改进，统一控件和对齐，提供键盘、焦点、错误和响应式状态；营销页面的视觉规则不机械套用到科研数据表。

## 2. 已验证的问题与抽样边界

基线为公开站点提交 `761bbc9`、页面数据标签 `v2026.09.03`。当时公开目录显示 10,507 个条目。使用固定种子 `20261001`，以 API 的一基页码和 `per_page=25` 抽取首页、末页与八个内部页：1、123、166、186、202、272、298、325、368、421，共 232 个材料。另检查了 11 个详情页。这些是审计请求的页码；当前 UI 每页 50 条、末页为 210，与审计分页不同。

这是跨页探索性抽样，覆盖排序靠前、中间及末尾条目；属于按页聚集抽样，不能据此给出全库无偏缺失率。

| 抽样现象 | 已核查数量 | 对用户的影响 |
| --- | ---: | --- |
| 可选出来源支持的 Tc | 175 / 232 | 仍需展示对应条件和来源，不能仅显示最高值 |
| Tc 未报告 / 无法追溯 | 53 / 232；4 / 232 | 两种状态应分开，不能一起写成 `Unknown` |
| 已选 Tc 缺方法 / 判据字段 | 53 / 175；94 / 175 | 这是原始字段缺失口径；实验结果需要区分电阻、磁化及 onset、midpoint、zero，计算结果优先核查计算方法，不生成实验判据任务 |
| 已选 Tc 有压力 / 未报告压力 / 压力含义不清 | 32 / 175；120 / 175；23 / 175 | 空压力不能默认为常压；上下限和范围不能变成精确测量点 |
| 已选结果可显示来源定位 | 0 / 175 | 有论文链接仍不足以快速核查具体数值 |
| Pairing / Unconventional / Competing order 未知 | 198 / 232；188 / 232；205 / 232 | 大量列对默认浏览价值有限，且未知不能视为否定 |
| 空间群待来源核查 / 未知 | 68 / 232；164 / 232 | 已有文字线索和没有线索应区分；空间群文字不是坐标结构 |
| 每行 `Operational policy: no findings` | 232 / 232 | 无异常的操作状态挤占版面，并可能被误读为科学认证 |

旧界面同时存在大量介绍性文字、上下错位的筛选控件、不可用相筛选和重复注释。改动后的同一桌面视口测量中，表格起点由约 726 px 降至 422 px；普通行高由约 116–131 px 降至约 67 px。这是本次视口的布局结果，不作为所有屏幕尺寸的保证。

## 3. 当前已完成的交付与实际数据试点

### 3.1 界面与数据边界

当前升级代码已实现：一句话介绍、基础与高级筛选分层、结果数量与排序工具栏、可折叠 `Data & methodology`、七列默认表格、科学列选择和按需证据展开。正常的 `no findings` 不再逐行占据核心区域；实际需要复核的异常仍应可见。

显示 Tc、压力和判据使用同一结果上下文。筛选命中的结果优先显示，目录最高 Tc 单独说明；来源年份与展示结果绑定。已有 URL 筛选状态继续保留，不支持的相筛选给出可恢复提示。方法、分类和结构证据各自保留其来源，不拼成一条虚构的联合实验。

后端新增有界、只读的来源检索与候选补全能力，以及独立的 MDR SuperCon、MP、COD、NOMAD 参考查询能力。多来源检索优先选取确有索引段落的论文，并在完整来源排序中分布抽样，避免第九篇论文虽有正文却始终被前八篇空来源挤掉。第二轮进一步按论文分配 chunk 名额，增加独立的来源分类陈述提取，并将实际查到的外部字段反馈到字段覆盖表。分类提取仍有明确的主体、措辞和召回边界，不能把待核查主张显示成正式分类。论文页和候选来源均提供经过格式检查的原始出版 / arXiv 链接。候选补全、外部参考和正式目录属性保持分层。详细技术边界和复现方式见 [材料补全实现说明](materials_enrichment.md)。

### 3.2 论文 chunks 试点

第一轮（2026-10-01）的只读生产导出覆盖 **19 个材料、15 个材料家族、2,257 条保留记录、23 篇来源论文、362 个当前 chunks**。当时按该轮来源适配口径排除 39 个自动生成的 Facts chunks；其余 323 个 chunks 的历史来源链未获完整验证，因此只能作为待核查检索线索。第二轮相同输入兼容性测试采用冻结适配器排除 41 个派生 / Facts chunks，得到 321 个来源捕获；两个口径分别保存，不能直接比较候选总数。

试点得到 **66 个去重候选事实**，关联 74 次保留记录匹配：22 个 Tc、4 个压力、2 个空间群、14 个方法、22 个样品形态、1 个结构描述、1 个 Tc 判据。相同来源事实关联多个旧记录，不代表多次独立实验。候选首次进入私有本地账本 66 条，重放新增 0 条、复用 66 条；没有晋升为正式属性。

另外核查了两份原始来源并制作 **41 个候选事实**的种子：YScH10 5 个，Pt 掺杂 BaFe2As2 36 个。该集合与 chunks 试点采用不同来源捕获和事实身份，不能简单相加后宣称增加了 107 个独立科学发现。

| 示例 | 可以恢复的信息 | 仍需保留的边界 |
| --- | --- | --- |
| YScH10 | 来源对应的 116 K、140 GPa，以及 Cmmm 的文字关联线索 | 116 K 与 YScH8 的 110 K 分开；140–250 GPa 稳定范围不当作 Tc 测量压力；属于计算报告；空间群关联待核查，没有完整坐标模型 |
| BaFe1.906Pt0.094As2 | 23 K onset 与 21.5 K zero resistance、I4/mmm、晶格参数、250 K 结构测量条件、原子位点及精修比例线索 | 标称组成与精修组成的关系仍待核查；母体 BaFe2As2 的表格值不填到掺杂样品；部分位点事实不等于完整 CIF |

这两个例子说明缺失不全来自“论文没有报告”，也可能来自多材料句子未正确对齐、表格列未绑定、实验判据未区分、样品组成未核对。原始来源分别为 [YScH10 论文](https://journals.aps.org/prb/abstract/10.1103/PhysRevB.109.054512) 和 [Pt 掺杂 BaFe2As2 论文 v2](https://arxiv.org/html/0912.2752v2)。

### 3.3 Materials Project 实际查询

对 19 材料样本中解析器允许精确组成查询的 14 个材料，完成了真实 MP 查询。Nb 返回 6 个条目，NbN 返回 8 个条目，另 12 个查询返回 `no_match`；5 个条目需要先解决组成解析或身份问题。本次没有服务不可用结果。`no_match` 仅说明本次查询没有匹配，不说明材料不存在或性质无法获得。

返回的 14 个条目保留为外部计算参考，包含结构相关字段和计算来源链接；没有写回正式属性或生产缓存，也没有确认这些结构就是来源论文中的样品相。后续补充了下面的 COD / NOMAD 真实查询，仍未运行新的第一性原理计算。

### 3.4 COD / NOMAD 补充查询（2026-10-02）

针对 MgB2、FeSe、NbN 做了真实、公开、只读的元数据查询，并保留私有响应捕获与哈希。初始 COD 试点共用 3 次请求；初始 NOMAD 试点共用 6 次请求，其中最初 3 次因字段选择不符合接口要求返回 HTTP 422，修正为具体字段后另 3 次成功。接口错误没有计作无匹配。

| 材料 | COD 返回并检查的记录 | NOMAD 匹配任务 / 本次检查 |
| --- | ---: | ---: |
| MgB2 | 2 | 89 / 10 |
| FeSe | 7 | 60 / 10 |
| NbN | 9 | 107 / 10 |

COD 的 18 条记录包含六个晶格参数、空间群、修订号与坐标可用标记；其中 3 条 FeSe 记录明确给出粉末衍射方法、293 / 295 K 及晶格不确定度。所有 18 条压力字段缺失，不能据此认定常压。两条名义 FeSe 的位点计算组成实际为 Fe0.996Se 与 Fe1.001Se，因此名义组成命中不能证明同一样品。空间群与多晶型继续分别保留，坐标文件链接不代表 SCLib 已核查完整坐标。

NOMAD 本次检查的 30 条任务覆盖不同结构，29 条明确标为 DFT，1 条方法缺失。程序字段包括 VASP、exciting、LOBSTER、FHI-aims 和 Quantum Espresso。其 AFLOW / OQMD 来源链接，以及一个 MP 来源任务，增加了计算来源追踪，也说明不同平台可能收录相同来源；这些条目不能计作独立实验。本次没有检查 archive 中的温压条件，状态应为“尚未检查”，不能写成“论文未报告”或默认 0 K / 0 GPa。

随后对其中 20 个已检查任务追加一次有界字段探测：19 个返回交换关联泛函名称及类型，3 个明确返回自旋极化设置。名称包括 PBE 与 PBEsol 对应的原始 NOMAD 交换关联项名称。它们来自可直接查询的 DFT 元数据，无需新计算或完整 archive 下载，因此纳入当前实现。保留原始名称与字段缺失状态；自旋设置描述该计算，不等于材料实测磁性；这些字段也不组成完整方法或收敛证明。这 20 个任务与前述样本重叠，不能相加统计为新增任务。

据此将 COD 结构参考和 NOMAD 计算任务参考纳入当前实现范围。它们与 MP 一样位于独立参考层，不覆盖目录的 Tc、配对主张或样品相；公开上线仍需完成相同提交的正式测试、发布及运行验证。

### 3.5 NIMS MDR SuperCon 实际数据核查（2026-10-02）

核查并捕获官方 **Ver.240322 / DOI 10.48505/nims.4487** 的 Oxide & Metallic 主表、Organic 主表、版本元数据和说明书。版本元数据明确标为 CC BY 4.0。O&M 文件为 19,875,381 字节、33,458 行、191 个唯一列；Organic 为 263,372 字节、569 行、49 列。实际文件有两行表头，不能机械沿用说明书中的三行表头描述。旧导入器的 Tc / 结构等少数列不能代表这份主表的全部信息。

O&M 实际包含 3,699 行空间群、13,126 行晶格 a、11,770 行晶格 c、15,969 行样品形态、4,051 行零电阻 Tc、17,117 行中点 Tc、4,606 行 R=100% Tc 和 5,624 行磁化率 Tc，以及少量 Hc2、相干长度、穿透深度、能隙、比热系数和同位素信息。这些是源表非空行数，不能计作新材料数、独立实验数或已经审核的正式补全。

在原始 232 个跨页样本中，168 个可以解析固定组成，52 个与 111 行源表精确成分匹配。其中 28 个材料有空间群线索，34 个有晶格 a，37 个有样品形态；14 / 34 / 16 / 19 个分别涉及零电阻 / 中点 / R=100% / 磁化率 Tc。这组列表样本没有逐条核对保留来源的化学式拼写，仅作为组成参考机会的上界。对 19 材料试点进一步应用每条保留来源的身份约束，14 个允许查询，其中 4 个命中 37 行：La0.4Sm0.6O0.5F0.5BiS2（2）、Nb（19）、NbN（15）、PbCe（1）。试点的 2,257 条现有记录均来自 arXiv / APS，未混入 NIMS 记录。PbCe 的命中是未观察到超导时的最低测量温度，不能填成 Tc=0。

当前已实现 **固定版本 O&M 的只读参考投影**，保存原表、行与资源哈希、物理行号范围、含版本的数据库条目编号、文献编号和归属说明；精确成分命中只建立参考关系。完整 33,458 行的 66 个投影字段与原表逐项比对，并验证可复现的压缩资源。每次最多显示 20 行，说明全部命中数、遗漏数和排序。Organic 虽已审计，身份和压力关系采用另一套字段，本次不纳入查询；无匹配只表示这个版本 O&M 范围内无匹配。

实际表格中存在单位缺失和未在说明书定义的代码，必须保留原值与解析状态：晶格 a 的 13,126 行中仅 9,180 行同时有单位；不能把其余值默认为 Å。`tcmeth` 中的 M / R / RM / MT 和样品形态的额外代码不能自行猜测。`pmax` 是最大施加压力，不是 Tc 对应压力；压力导数单位中有不合维度的文本，不能自动规范化。`tcn` 的 483 个零值保持为来源测量下限，不作零温超导结论。衍生性质保留 WHH、外推或其他原始方法描述；方向明确指来源声明的磁场方向，不擅自解释为相干长度的向量方向。该投影也没有逐篇核查文献撤稿或验证样品相；这些边界随参考条目展示，不冒充正式科学审核。

旧导出器中将 DOI 10.48505/nims.3735（Supercon 2 Dataset）误标为 MDR SuperCon 版本的静态声明已修正。一般性的旧 `nims` 标签不足以确定原数据集和许可，必须取得来源凭证；新版 240322 的许可不会自动赋给旧记录。历史记录和已生成的旧导出文件保留。

### 3.6 第二轮：公平来源读取、分类陈述与实际字段参考（2026-10-02）

**有界读取的预算按论文分配。** 每次最多检查 32 条当前有效记录、8 篇来源论文、合计 40 个 chunks 和 120,000 个字符。40 是本次请求的总额度，不是每篇 40 个。先统计每篇索引及长度合格的 chunk 数，再轮转分配名额；每篇内部优先材料公式和表格，取完整的 1–20,000 字符段落。字符预算不足时记录遗漏原因，不截断正文；取文本时重新核对测得长度，防止并发修改扩大读取范围。每篇分别显示考虑、检查、提供、排除、遗漏和截断状态。论文数量限制、权限限制、旧来源、派生文本和字符预算仍可能使某篇没有可用证据；公平分配不等于全文已读完。

**分类陈述有独立提取契约。** 当前 `material-classification-candidates/1.0.0` / `materials-source-statement-extractor/1.0.1` 支持配对、非常规主张、能隙结构、来源报告的序及明确竞争关系。保留 `reported`、`fitted`、`proposed`、`not_detected` 四种措辞。无节点能隙不能转换成 s-wave 或常规超导，odd parity 不能转换成 p-wave，某个测试窗口未探测到 AFM 不能转换成材料全局的 false。主体须为局部精确组成、局部唯一 x 赋值或同篇论文明确编码的样品别名提案；别名定义和陈述各有来源锚点。比较对象、被引工作、单元素衬底、拒绝或含糊假说、否定对象不清、正负陈述冲突及多温压 / 磁场状态进入复核队列。

## 4. 字段补全路线：逐项决定，不统一填空

“论文 chunks 可补”指找到了可归属对象和条件的原始报告，而不只是搜索命中。第三方数据库提供相应数据库中的实验结构或计算参考，不能自动替代论文样品。计算结果标为 `Computed`，实验报告标为 `Observed`；跨来源一致性可以支持关联，但不能制造实验验证。

| 字段 | 优先从论文恢复 | 第三方参考路线 | 必须新增计算或实验的情形 | 进入正式展示的条件 |
| --- | --- | --- | --- | --- |
| Tc 与误差 | 正文、表格、图注、补充材料；保存 onset / midpoint / zero | NIMS MDR SuperCon 中的不同 Tc 判据与其他论文 / 已有计算可分别列为参考；MP 常规摘要不提供实验 Tc | 未报告且希望预测时需适用的理论模型；实际 Tc 需实验测量 | 样品、方法、判据、压力、实验或计算来源均明确；冲突报告并列 |
| Tc 对应压力、磁场、温度条件 | 同一句、表格列头、实验段及计算条件 | 只能补该外部条目自身的条件 | 原文没有且要确定实验条件，需要原始记录或重新实验 | 数值、单位、范围和上下限关系完整；未知压力不作为 0 GPa |
| 测量方法与 Tc 判据 | 电阻率、磁化、热容描述及曲线定义 | MDR 可补其明确的 Tc 判据与测量代码；结构数据库不能补超导测量方法 | 方法缺失需作者资料或新实验；不能由材料家族猜测 | 方法与对应结果绑定，onset 和零电阻不合并 |
| 精确组成、掺杂、同位素、氧含量 | 合成、成分分析、样品编号、精修与补充表格 | COD 的对应实验结构；MP 精确组成参考；母体只能作上下文 | 不确定真实组成需成分或占位测量；建模需指定组分与无序近似 | 标称与实测分别保存；变量 x / δ 保留；不丢掉掺杂或同位素 |
| 样品形态与制备 | 单晶、多晶、薄膜、厚度、基底、退火等实验描述 | MDR 提供其来源样品形态与文献记录，但不能据此认定同一样品 | 缺失需原始实验记录或新表征 | 与样品或批次绑定，薄膜界面与体相分开 |
| 空间群、相、晶体结构文字 | 结构段、衍射结果、结构表及图注 | MDR 的来源结构文字及 COD、MP、NOMAD 的相候选 | 无已知结构时需衍射或结构搜索；预测相不等于实验相 | 原始来源关系先核查；区分 proposed / reported / reviewed |
| 晶格参数、原子位点、占位、CIF | 表格、可下载 CIF、补充材料 | MDR 可提供有单位的晶格参考；COD 用于已发表晶体结构；MP / NOMAD 提供对应计算结构 | 条件不匹配时可做指定条件的结构优化；实际结构仍需实验 | 表格列与样品绑定；温度、压力、误差、坐标系、占位和文件来源完整 |
| 能带、DOS、费米能、磁矩 | 已发表计算图、数据文件与方法 | MP 或 NOMAD 的对应计算任务 | 无合适任务或所需掺杂、压力、磁序不同，需新计算 | 记录结构、泛函、磁序、SOC、方法与能量参考；结果标为计算 |
| 形成能、距凸包能、热力学稳定性 | 对应计算方法及条件 | MP、NOMAD 对应组成与任务 | 高压、有限温、不同参考态或方法时需相应焓或自由能计算 | 不能用标准条件稳定性替代高压稳定性；参考体系与条件明确 |
| 声子、动力学稳定性、EPC、λ、ωlog、μ* | 论文表格、谱函数、计算补充资料 | NOMAD 或论文归档中已存在的相同计算 | 缺失且属于适用体系时需声子、电子声子耦合和收敛计算 | 保存压力、结构、k/q 网格、展宽、μ* 等；虚频与非谐处理说明 |
| 配对对称性、非常规分类 | 原始实验或理论明确报告及证据 | 其他论文可增加独立主张；MP 的电子能带带隙不替代超导能隙或配对证据 | 实验判定常需多类探针；理论推断需适用模型 | 展示“来源报告什么”，保留争议；无报告不显示否定 |
| 竞争序、磁序、相图 | 同一样品和条件的磁性、结构、密度波等报告 | 外部磁性计算可作计算参考 | 温压掺杂相图可能需多点实验或模型 | 与材料状态、温度、压力、掺杂绑定，不从家族继承结论 |
| Hc2、Hc1、穿透深度、相干长度等 | 实验数值、拟合公式、方向及温度 | MDR 明确温度 / 方向的条目、其他论文或计算结果独立列出 | 无报告需专门实验；派生值只能按明确模型计算 | 实测与派生分开；方向、温度、公式、误差和有效范围明确 |

执行队列还应区分确定性数据处理与新的科学计算。单位换算、CIF 解析，以及依据来源所列对称操作展开等价位点，应保存原始文件、操作和算法版本；得到的派生值不能标作原文印刷值或新实验。缺少原子位点与占位时，空间群标签不能补成完整坐标结构。图像读数也需要明确精度与读取方法，不能包装成表格中的精确原值。

MP API 可查询结构和摘要字段，并通过 property origins 查到属性对应计算任务；需要进一步检查任务的计算方法，而不把摘要当作全部方法信息。[MP 查询文档](https://docs.materialsproject.org/downloading-data/using-the-api/querying-data)

执行时再按实际返回字段判断可补范围。MP提供结构、能带、DOS、部分声子及计算任务查询，但专门DFPT数据仅覆盖部分条目；查询到结构或声子不等于查询到电子声子耦合、超导能隙或实验Tc。[MP 当前查询示例](https://docs.materialsproject.org/downloading-data/using-the-api/examples) NOMAD的输入方法、原子系统与计算输出分别存放，必须沿具体任务检查这些关系；摘要中的组成命中不建立与论文样品的对应关系。[NOMAD 计算数据结构](https://nomad-lab.eu/prod/v1/docs/examples/computational_data/metainfo.html)

MP 的标准组成相图建立在 0 K、0 atm 的条件下，因此高压氢化物不能直接借用这类稳定性结论。高压与有限温比较需要合适的焓或自由能处理。[MP 相图方法](https://docs.materialsproject.org/methodology/materials-methodology/thermodynamic-stability/phase-diagrams-pds)

COD 用于晶体结构参考检索；命中后仍要核对文献、名义与位点组成、温度、压力、来源方法和结构文件。COD 可包含理论条目，因此不能仅凭数据库名称把每条结果认定为实测。[COD 查询与版本接口](https://wiki.crystallography.net/RESTful_API/) 其晶格长度单位为 Å，角度为度，温度为 K，结构与衍射测量压力为 kPa；实现中需要逐项保存来源单位及不确定度。[COD 字段与单位](https://wiki.crystallography.net/cod_mysql_schema/)

NOMAD 的公开元数据与归档接口能够检索已有任务及其处理后的数据，适合补方法、程序、已记录的 DFT 泛函与自旋设置和任务来源。当前元数据查询不等于完整 archive 核查；后续仍需确认输入结构、完整方法、磁序和计算条件。[NOMAD API 文档](https://docs.nomad-lab.eu/1.4.3/howto/manage/program/api.html)

## 5. 身份与条件是补全的强约束

### 5.1 区分材料、样品、状态与单次结果

至少保存四层关系：材料组成身份 → 样品或计算结构 → 温压磁场等状态 → 单次性质结果。材料行是这些结果的导航入口，不能把不同论文的最高 Tc、另一种相的压力、第三个样品的空间群组合成同一测量。

同式材料可能有多晶型、磁序、缺陷、氧含量、厚度或制备差别。掺杂体系保留标称组成、实测组成和变量含义；样品编号需要明确绑定到材料。精修占位比例与目录化学式的关系可以作为核查提案，不自动成立。高压相不由常压结构替代；薄膜与界面不由体相母体替代；同位素不被普通元素查询抹掉。

### 5.2 保存来源与认识状态

每个候选记录材料或样品关联、来源论文、原始来源版本或捕获依据、内容哈希、chunk / 页 / 表 / 图定位、原始文本值、单位、规范化值、方法、条件和审核状态。已有 paper 行的快照哈希只能证明捕获了哪个数据库快照，不能冒充出版版本。

自动生成 Facts、派生摘要和来源不清的历史 chunks 不能被标为原始段落。正文检索失败不意味着论文未报告；只读请求的有界 chunk 列表也不代表全文、补充材料或整个材料记录集已查完。复核状态追加保存，保留原值与历史解释。

显示状态采用有解释的词汇：

| 状态 | 含义 | 页面建议 |
| --- | --- | --- |
| Reported | 来源明确报告，尚不等同科学结论被独立验证 | 显示值、来源及条件 |
| Pending source review | 有候选证据，关联或来源待核查 | 详情中显示候选与待核查原因 |
| Not extracted | 已有来源，但当前未完成该字段提取 | 简短占位，详情中显示补全路线 |
| Not reported in reviewed scope | 明确核查过的范围内没有该报告 | 标明正文 / 补充材料的核查范围 |
| Untraceable | 旧值无法定位到合格来源 | 保留历史记录并显示问题，避免当作已支持值 |
| Conflicting reports | 多个来源报告不同结果 | 展示条件与判据，允许比较，不静默选一个“真值” |
| Not applicable | 对该对象或方法不适用，并有理由 | 从相应覆盖率分母中排除，保留理由 |
| External reference | 外部库条目，其样品或状态关联未确认 | 单独展示库 ID、计算或实验类型和匹配状态 |

常规页面不重复显示 “not a negative finding”。其含义在全站方法说明和字段帮助中解释一次。异常记录继续提供原因、受影响字段与来源，`no findings` 只属于操作检查状态，不表示有效超导、科学认证、独立复现或 ML 可用。

## 6. 顶部、筛选、表格与详情的统一设计

### 6.1 顶部与筛选

顶部只保留标题、一句用途说明和数据入口。较长的来源政策、分类边界和筛选语义放入 `Data & methodology`，默认收起，可直接链接。保留独立结果数量和更新时间，发布标签与来源年份分开。

基础筛选保持一组对齐的控件：Family、Tc ≥ (K)、Pressure ≤ (GPa)、Result origin、Apply、Clear。标签在上、输入框等高，使用网格布局；桌面稳定分列，窄屏自动换行，操作按钮位置一致。

高级区域放配对、非常规分类、竞争序、明确常压结果、来源级别、来源链接数等低频筛选。不可用的 reviewed phase 不占据基础筛选主位置；说明原因和恢复办法，不用截断的禁用输入框误导用户。已选条件显示可删除 chips，保留 URL 状态，支持返回和分享。

所有阈值注明单位和关系；压力未知的记录在压力阈值下默认不视为符合。若允许纳入未知压力，应是明确的独立选项。分类筛选注明它筛的是来源报告，不能暗示与当前 Tc 是同一次观测。

### 6.2 默认表格

默认七列：**Formula、Family、Reported Tc (K)、Conditions、Source year、Sources、Evidence status**。Conditions 包含该 Tc 的压力、origin、方法或判据摘要；复杂条件展开查看。来源数量注明是链接数，不能描述成独立实验数量。

正常记录不逐行展开长政策说明。缺失值用短词或破折号配合可访问帮助；分类、配对、竞争序、结构等作为可选列。Formula 与 Tc 是主要视觉锚点，数字按列对齐，单位放表头或清楚的条件行。长公式允许适当换行，表格自身横向滚动，避免整个页面溢出。

默认排序明确是当前所选结果还是目录最高 Tc。筛选命中 21.5 K 零电阻结果时，不能主单元格仍显示另一条 23 K onset 结果而让用户误读。目录最高值可以次级显示并说明来源。取消“完整度六格全绿”等无定义指标，改为可核查的证据定位和条件状态。

### 6.3 证据展开与材料详情

点击值或证据状态后展开对应结果：数值与误差、实验或计算、方法、判据、样品和状态、来源版本、定位、核查状态、替代报告。详情页按结果和来源组织，方便比较同材料的不同条件。

结构区区分三种信息：来源文字结构主张、经过核查的坐标文件、第三方结构参考。外部参考展示所有保留的多晶型，不自动选择最低能结构代表实验样品。计算参考另列方法和条件。尚无坐标时显示“没有可用坐标文件”，仍可显示已核查的空间群或晶格报告。

候选补全区展示“已有何种线索、待核查什么”，与正式属性清楚分组。只展示有使用价值的事实和来源定位，不公开私有全文捕获或把底层哈希、策略版本放成每行主文案。详细数据契约可保留在导出或方法说明中。

分类陈述独立折叠，默认先看有限数量，按需展开本次返回候选与需复核发现；显示原始措辞、字段、来源和未完成的主体 / 状态关联，不生成全局真假标签。字段覆盖表新增按来源区分的实际查询参考列，明确“没有返回此字段”和“组成没有匹配”的区别；仅提供补全路线时显示尚未查询。外部面板保持按需加载，参考条目与正式属性分别计数。

### 6.4 可读性验收

以同一视口和同一材料样本做前后比较，检查顶部高度、首屏可见记录数、定位一个 Tc 来源所需步骤及筛选控件对齐。覆盖桌面 1280×720、较大桌面与 320–390 px 手机宽度；检查键盘操作、焦点、标签、色彩对比、加载 / 空结果 / 请求失败状态。行高以普通内容紧凑为目标，不通过固定高度裁掉公式、条件或真实异常。

## 7. 从检索到可用属性的可落地流程

1. **生成缺口队列。** 对现有结果按字段列出缺口，区分缺值、缺条件、缺来源、来源冲突、来源未查完和字段不适用；排序优先来源丰富但定位差的条目。
2. **限定材料的来源范围。** 从当前有效记录取得确切论文 ID，核对原始来源与综述、引用他文关系。先检索已有原始 chunks；历史来源不清的段落只用于定位原文。
3. **重取必要证据。** 在访问许可允许时获取正文、表格、图注、补充材料和结构文件。保存不可变捕获、来源版本与哈希，记录哪些范围已经核查。
4. **生成待核查候选。** 绑定句子主体和表格列，保存原始单位、范围、括号不确定度、样品编号、方法与条件；去重事实并保留其全部来源关联。
5. **审核关联与抽取。** 对照原文检查材料身份、母体与掺杂、实测与计算、压力与稳定范围、onset 与 zero、结构测量温度等。自动检查减少机械错误，研究人员负责含义和关联复核。
6. **建立适合字段的审核与追加入口。** 先核查现有流程支持的字段和权限。当前通用来源候选服务只读，Tc 交接生成待审记录；并不存在适用于全部种子、外部结构和派生量的通用晋升入口。后续需补充相应字段的适配和审核契约，建立来源定位、样品和状态关系，再追加正式记录。保留旧值与审定记录；候选服务不直接修改正式属性。
7. **补外部参考，再决定计算。** 外部条目按精确组成检索，保存所有相与任务来源；匹配不成立时继续作为参考。缺口确实不能从已有可信来源得到且有明确使用场景时，才形成计算或实验任务。
8. **回算读模型与覆盖率。** 更新页面和索引，显示本次核查范围、尚未解决原因和数据版本；追踪每批变化，不把来源抓取成功当成提取完成。

有界在线查询保持可控延迟和成本；较大的全文、补充材料和历史复核进入后台批次。未完成的分页、截断或超时必须留有状态，不能输出“没有报告”。

以下为建议排期，按验收结果扩展规模；计算和外部来源授权可能影响后两阶段。工程、数据和科学审核责任可由现有团队成员兼任，但审核结论应可追溯到人员或规则版本。

| --- | --- | --- | --- | --- |
| P0：界面与证据契约 | 第 1 周 | 前后端、数据工程 | 完成当前界面变更的正式发布与公开验证；七列、筛选、详情、异常说明；固定抽样基线与字段状态字典 | URL 与筛选语义一致；Tc / P / origin 不跨结果拼接；正常提示收起、真实异常可见；保留数据和回滚路径 |

## 9. 正确性、覆盖率和成本指标

每项指标写清数据版本、材料或结果范围、字段、核查状态和分母。候选数量、来源数量、独立实验数量分别统计。下面的质量目标是后续建议验收标准，不是本次试点已经达到的全库指标。

| 指标 | 定义与建议目标 | 防止误读的要求 |
| --- | --- | --- |
| 来源与数值抽取准确率 | 在人工核查基准集中，数值、单位、对象、判据和条件均正确的比例；建议达到 ≥98% 后扩批，并给出样本量及置信范围 | 衡量是否忠实表达来源，不等于来源科学结论正确；高风险身份错误必须单独阻断 |
| 身份与状态错误 | 跨材料、跨样品、母体代替掺杂、实验 / 计算混淆、错误压力关联的例数 | 发现一例就暂停该错误类型的晋升，查清受影响批次；有限样本“零发现”不能证明绝对零错误 |
| 已有值可追溯率 | 可定位到合格来源具体段 / 页 / 表 / 图的正式结果数 ÷ 目标范围内正式结果数 | DOI 或论文链接本身不算具体定位；历史无法追溯值另计 |
| 条件完整率 | 在需要该条件的 Tc 结果中，具有已核查压力、方法、判据、样品关联的比例，分别报告 | 不把计算 μ* 等不存在于实验的方法字段强行纳入；不适用必须有理由 |
| 人工基准召回率 | 基准来源中可恢复事实被正确提取的比例，按字段和来源类型分别统计 | 全文捕获完整不代表抽取召回完整；不同家族不能只给一个混合平均值 |
| 分类陈述与复核收益 | 独立记录已审陈述数、正确主体 / 措辞比例、发现原因分布、人工可恢复而语法未命中的事实数 | 当前 2 条主源候选、122 条历史发现属于不同队列；不把原文陈述、未探测到和科学验证混成一种结论 |
| 来源核查覆盖率 | 正文、补充材料、结构文件各自完成核查的论文或来源数量 ÷ 目标范围内对应数量 | 有界 chunk 查询、摘要读取和全文核查分开统计 |
| 正式属性补全收益 | 新增通过审核的字段或补全条件数、解决来源缺口数、冲突显式化数 | 待核查候选和外部参考不能计作正式补全 |
| 外部匹配质量 | 查询成功率、真实无匹配率、需解析比例、审核后身份匹配比例 | 组成查询命中与样品 / 相匹配是两个阶段；接口错误不计作无匹配 |
| 结构可用率 | 具有来源、条件、占位与完整可校验坐标文件的目标结构数量 | 空间群或部分位点文字不计完整结构；晶体文件可用不表示超导性已验证 |
| 页面使用效率 | 固定任务下筛选、比较条件、打开证据的完成率与步骤 / 时间；首屏可见有效信息 | 与同一视口的旧版比较；真实异常和长公式允许增加行高 |
| 运行与审核成本 | 每 100 个材料的查询、提取、审核耗时；每个晋升事实的成本；待审积压和 API 延迟 | 批次扩张受质量与成本共同约束，不靠吞吐量单独决定 |

目标是可解释地增加可用信息。不同家族适用字段不同：超导配对、复杂竞争序和高压结构往往不能统一追求同一种“百分之百完整”。页面可展示字段级覆盖和核查进度，不生成一个没有科学含义的总完整度分数。

## 10. 新计算与实验的任务边界

计算任务先列出输入结构及其来源、组成与占位模型、目标压力 / 温度、磁序、方法、收敛标准、所需资源和要回答的问题。任务输出保存软件与版本、参数、输入输出、工作流与结果哈希，标明哪些值是直接计算、哪些是派生估计。

对适用电子声子机制的体系，可评估结构优化、声子与电子声子耦合，再在明确参数下估计或求解 Tc。必须检查动力学稳定性、采样与收敛，必要时评估非谐效应。EPW 的相关方法以电子声子问题为基础，不能直接用于证明铜氧化物或其他体系的非常规配对机制。[EPW 理论文档](https://docs.epw-code.org/Theory.html)

λeph 与 ωlog 可从对应结构、压力、磁性及采样条件下的电子声子计算获得；μ* 常是替代昂贵库仑相互作用处理的半经验模型参数，须记录其来源、取值依据和敏感性分析。论文或补充材料未取得时，μ* 保持来源不可获取；不能默认补成 0.1，再把所得 Tc 当作恢复的论文结果。MP 的结构、能带、DOS 或部分声子数据是已有计算参考，本身不足以提供 Tc、电子声子参数或配对证据；NOMAD 的 method / system / calculation 关系也应核查到实际任务。[EPW 库仑项与耦合理论](https://docs.epw-code.org/Theory.html)、[MP 查询示例](https://docs.materialsproject.org/downloading-data/using-the-api/examples)、[NOMAD 计算数据结构](https://nomad-lab.eu/prod/v1/docs/examples/computational_data/metainfo.html)

对实验 Tc、体积分数、实际占位、配对对称性或独立复现等问题，计算结果不足以替代测量。若文献和原始记录都没有合格信息，应明确列为实验缺口并设计相应表征。页面可以因此更加准确，即使某些字段仍然没有值。

## 11. 发布与数据运行安排

界面与只读能力可先发布；候选核查、正式属性追加和计算工作分批推进。正式发布按仓库既有测试、安全、镜像及部署流程验证相同提交，确认备份、schema、健康检查、版本和公开页面；数据库变更遵循 [schema 发布规则](SCHEMA_ROLLOUT.md) 与 [部署说明](DEPLOYMENT.md)。

## 12. 有限来源字段批次与显示交付（2026-10-02）

在前述综合方案基础上，继续执行了一个有明确分母的来源补全批次：10 个目标材料 / 来源案例、44 项计划任务；另外补充了 Pt 来源的 5 项制备与比热任务。它们属于有目的的来源核查，不是新的随机样本、49 次实验或 49 个已批准的正式属性。

### 12.1 实际可取得的信息

### 12.2 保留真实原值与单位来源

来源核对将“原文印刷的单位”和“数据库 / CIF 字段语义给出的规范单位”分开。例如 CIF 的分数坐标、占位与 Z 没有印刷单位词，`raw_unit` 为 null，并记录规范单位的字段依据；不把自动规范化后的单位伪装成原文文本。第一批旧对象另行保留，新对象及差异回执分别保存，没有改写来源捕获或历史记录。全部原值、精度、来源哈希和定位保留。

### 12.3 新页面的信息层级

材料详情的额外来源观察默认折叠，仅在当前有效来源响应与固定种子 / COD 修订匹配后出现。独立来源页按来源窗口提供值、模型或方法角色、条件、原始定位及下载；共同条件在组头只显示一次，逐项只显示不同的模型或表格行，避免再次制造逐行长提示。

后续批次采用来源组折叠、逐字段专业标签和可展开的来源定位。单位冲突、不可获取和样品对应未建立保留为有意义的状态；来源 ID、哈希、完整定位与限制放入折叠层和 JSON 下载，核心浏览区域优先展示科学数值与适用条件。

提供两份公开元数据与 SHA-256 旁文件，以及当前窗口 / 来源组的真实 JSON 下载。下载来自当前验证后的对象或固定来源快照，不包含整篇原文、PDF / CIF 重托管内容或私有审核备注。材料切换、失去来源匹配、修订改变或下载失败不能继续导出旧结果。

### 12.4 验收与正式入库边界

原始 15 项做过 310 个独立来源检查；第二批最终原始表达对象做过 536 个独立来源 / 定位 / 语义检查，均未发现实质差异。这些是 AI 辅助核对，不是人工领域审核或全库准确率。单位来源修正及公开投影另作逐值差异检查。

本批不改 API / schema / 原有种子和保留结果，不增加人类审核、科学批准、ML 许可或正式属性晋升。正式追加需要适用字段对象、确切来源版本、材料 / 样品 / 状态关联、冲突处理和有权限的审核决策；当前 Tc 纠错接口不是所有性质的通用导入器。来源表达先为检索、比较和核查提供实际信息，正式材料属性完成率仍须分别统计。

界面、来源数据及下载必须在同一提交通过测试和构建，再经正式签名镜像、部署及公开版本 / 桌面 / 窄屏 / 键盘验收。尚未完成的流水线或本地截图不计为上线。第一版发布提交保持冻结，后续来源字段在独立工作树交付，避免持续重启已经运行的检查。

实现契约与来源窗口示例见 [来源观察说明](materials_source_observations.md)。
