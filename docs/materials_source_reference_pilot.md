# Materials source reference pilot

The Materials methodology menu links to `/materials/source-references`.
This researcher-facing page provides seven scoped CrB2 paper items and three
independent COD references. Downloadable metadata is packaged at
`/research-pilots/materials-source-references-2026-10-02.json`, with a separate
SHA-256 file. These are source items, not ten independent experiments.

The paper items preserve the rounded 7 K / approximately 100 GPa summary,
the approximately 7.3 K / 110.4 GPa transport result, apparatus-dependent
measurement methods, Figure 2's 90% resistivity definition, GL-fitted Hc2(0),
the dependent coherence length and the separately scoped structure description.
All fourteen text anchors omit raw quotations. Official PDF page links,
quantity roles, derivation dependencies and the captured file hash are retained.
Publication revision, current source lifecycle and catalogue-result associations
remain unresolved.

The COD entries preserve declared cell metrics, uncertainties, temperature and
pressure availability, bibliography, file revisions and hashes. The FeSe CIF
contains 295 K and Fe occupancy 0.996(3). Its version URL was unavailable at
capture; the successful current download contained revision 176432. A future
download may return different bytes. The other two captured CIFs succeeded at
their revision URLs. Unknown pressure is not converted to ambient pressure.
Syntax, listed sites and declared operations were inspected using isolated
Gemmi 0.7.5; independent space-group inference, checkCIF and refinement were
not performed. COD's captured entries explicitly link to CC0-1.0.

The JSON contains no catalogue/material/result association IDs, retained record
references, private paths, fulltext or original PDF/CIF files. The inspected
historical catalogue placed MgB2 and FeSe in disputed/archive scope; their
independent source metadata does not restore catalogue visibility. Existing
material-bound eligibility guards remain unchanged. Source-inspection records
are separate from catalogue projections under `VISIBILITY_POLICY.md`.

This frontend-only addition does not change any of the 635 R8 native capture
inputs, the five packaged API resources or scientific ingestion. It adds no
application seed, accepted property, source permission, human/domain review,
ML-training admission or production-data write. Static metadata checks and
rendering checks do not replace those scientific processes. The first small
formal curation batch and a generic field-specific review/append adapter remain
future work.

Release acceptance must check the final deployed revision, page navigation and
narrow-width readability, the ten source items and their separate conditions,
and downloaded metadata bytes against the packaged SHA-256. Native captures
retain their existing API-source scope; final-head frontend and security CI,
image scan, signed publication and public acceptance cover the added page.
