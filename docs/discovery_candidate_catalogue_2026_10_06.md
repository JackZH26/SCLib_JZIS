# Discovery candidate catalogue and research workspace

The Discovery landing view is a material list. Research plans, scientific-property
companions, source studies, calculation tools, methodology and the historical feed
live in a second **Research & tools** tab. Existing inner anchors continue to select
and reveal their tab; tab changes preserve local drafts.

## Candidate data boundaries

| Catalogue | Evidence supplied | Score and order | Publication scope |
|---|---|---|---|
| Published RPS assessments | A complete, verified frozen release, with its own campaign, budget, states and actions | Highest published action score per material ID and role, descending; null scores last; ties retain frozen order | Existing RPS distribution admission and account separation |
| Structure proposals | Three retained CIFs derived by changing one Mg site of a pinned MgB₂ supercell, with source revision, composition and byte hashes | Score and rank are null; retained proposal order has no potential interpretation | A separate website research-proposal catalogue, not an RPS or formal scientific release |
| Scientific companions | Separately admitted property projections | Existing property contracts | Existing scientific admission; a proposal is not an accepted property |

The structure-proposal catalogue is useful before a calculation is commissioned.
It does not create formal material/state/action records, supply human review receipts,
or relax the existing RPS and scientific distribution requirements. A single owner
can request that these clearly labelled proposals be displayed on the website;
that instruction does not become independent scientific review or a three-account
approval. Deployment still follows the engineering release process.

## First concrete proposal batch

| Formula | Change to a 2 × 2 × 2 MgB₂ supercell | Retained atoms | Current state | Next action |
|---|---|---:|---|---|
| Mg7AlB16 | Replace one of eight Mg sites with Al | 24 | Unrelaxed, unranked | Review state, methods and inputs |
| Mg7CaB16 | Replace the same Mg site with Ca | 24 | Unrelaxed, unranked | Review state, methods and inputs |
| Mg7B16 | Remove the same Mg site | 23 | Unrelaxed, unranked | Review state, methods and inputs |

The 12.5% figure means one modified site divided by eight original Mg sites. It is
not a measured concentration. COD 1526507, revision 176429 is the frozen parent
coordinate source. MgB₂ is a reference, not a fourth candidate. The proposed ordered
configuration is not evidence of novelty, synthesizability, stability, superconductivity,
or a 300 K transition. Parent results and unrelated AlB₂ calculations are not inherited.
No pressure, temperature, charge or magnetic state is assigned to the proposals.

All six physical axes remain unknown. RPS score, rank and human scientific review
remain null. A future M4 Mac mini is presently unavailable; its specification alone
cannot supply confirmed execution access, cost bounds or a campaign budget.

## Presentation and verification

- One material row by default, containing formula, host/modification, research priority,
  state and the next action. Click its formula for source, state, physical evidence and files.
- A compact shared explanation replaces repeated policy paragraphs on each row.
- Search and modification filters affect the proposal table. An empty filter result is
  distinct from catalogue verification failure.
- CIF and JSON downloads retain unknowns and exact CIF bytes. The validated catalogue
  exposes no local filesystem paths, account data or private resource declarations.
- A missing or invalid RPS service is shown explicitly. The separate proposal catalogue
  never impersonates an RPS response, accepted scientific property or an automatic fallback.
- New scored candidates require the existing actual evidence/action/budget/review workflow;
  a score is research priority within a campaign, not superconductivity probability.

This change prepares a reviewable website release. It does not record a deployment
or scientific approval merely because the code and source-integrity checks pass.
