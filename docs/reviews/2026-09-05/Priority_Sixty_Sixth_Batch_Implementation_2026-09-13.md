39 subtests passed, 94.75s. The corpus fixtures tried to load `cl100k_base` with
no usable ranks cache. Its library attempted HTTPS retrieval, which the existing
offline socket guard refused. This was not a permission to remove that guard.

- All three Python CI jobs now prepare tokenizer ranks after the locked package

  round-trip with sockets blocked, absent/corrupt cache rejection, and both

  scientific corpus test was introduced.
