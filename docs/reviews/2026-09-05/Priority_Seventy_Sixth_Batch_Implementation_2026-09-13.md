## Why this is the next step

[ML08 #54](https://github.com/JackZH26/SCLib_JZIS/issues/54) asks which priority
fields are recoverable at acceptable curation effort before scaling ML work.
The existing canary already contains the relevant field/group accounting, and
the offline report already contains the complete ledger. This implementation
uses that existing evidence instead of adding redundant database columns,
statistical endpoints, compiler versions or automatic scientific judgements.

The user-facing result is **Show verified field report** on the English private
review workbench. The complete behavior is specified in
[ML_PILOT_QUALITY_REPORT.md](../../ML_PILOT_QUALITY_REPORT.md).

## Delivered behavior

- Explicit opening only after the original-file scope and authenticated
  canary/context byte replay have passed. A session refresh precedes local reads;
  actual canary/conclusion bytes are hashed again against the bound originals.
  No additional source upload, declaration, cohort-coverage request or write.
- Separate 60-event, effective atomic-result, event-association, identity and
  all-revision denominators. Zero-result cohorts remain explicit empty atomic
  denominators, not successful recovery or synthetic negative examples.
- All eleven priority fields, all seven availability states and candidate
  recovery distinct from extraction correctness. Pending/rejected results are
  not silently dropped to improve completeness.
- Recorded total and field-specific minutes with timed-record coverage;
  unknown versus measured zero, historical revisions, partial effort and
  display rounding are explicit. Frozen family/source/stratum views use their
  own event denominators and stored group total effort.
- Separate typed errors and latest comparisons. No independent-work count,
  accuracy percentage, material-family ranking or scientific pass threshold is
  inferred from these counts.
- Original keep/narrow/defer and go/narrow/stop proposals, reasons and
  limitations are displayed, never generated or applied. Private text remains
  escaped and inert; source URLs are not followed. Small groups are not public
  aggregates or anonymized data.
- English labels and en-US number formatting, focused report heading,
  keyboard-scrollable tables and reset-safe group selectors. Account/input
  changes and failed rechecks clear old report content. Obsolete local reads
  cannot restore a report after an authenticated-account change.

The summary deliberately omits full source prose, typed scientific result rows,
each individual review and group-by-field timing. Those remain in the
[complete independently verified private report](../../ML_PILOT_REPORT.md).
Original context bytes are not displayed, but supplied conclusion prose can
itself contain private source text; this is not a redacted report.
